Claude Code와 함께 마크다운 블로그를 만들면서, 웹의 세 가지 기본 기술이 각각 무슨 일을 하는지 또렷해졌습니다. 짧게 정리해 둡니다.

## HTML — 구조

HTML은 **페이지에 무엇이 있는지**를 정합니다. 이 블로그에서는 이런 일을 맡았습니다.

- `header`, `main`, `article`, `footer` 같은 시맨틱 태그로 페이지의 뼈대를 만듭니다.
- 글 목록은 `ul`과 `li`, 날짜는 `time`으로 표현합니다.
- 화면에 보이는 모양은 신경 쓰지 않고, 내용의 의미만 담습니다.

## CSS — 모양

CSS는 **어떻게 보이는지**를 정합니다.

- 색과 간격을 `tokens.css`의 변수로 모아 두었습니다.
- 다크 모드는 같은 변수를 `[data-theme="dark"]`에서 다시 정의하는 것만으로 동작합니다.
- 모바일 우선으로 작성하고, 화면이 넓어질 때만 `min-width` 쿼리로 덧붙입니다.
- 본문 폭을 `65ch` 안으로 제한하니 글이 훨씬 읽기 편해졌습니다.

## JavaScript — 동작

JavaScript는 **무엇이 일어나는지**를 정합니다.

- `fetch`로 마크다운 파일을 불러옵니다.
- 직접 만든 변환기가 마크다운을 HTML로 바꿉니다.
- 주소의 `#` 뒤 부분을 보고 목록과 글 화면을 오갑니다.
- 테마 버튼을 누르면 선택을 `localStorage`에 저장합니다.

## 한눈에 보기

| 기술 | 역할 | 이 블로그에서 |
| --- | --- | --- |
| HTML | 구조 | 페이지 뼈대, 글 목록 |
| CSS | 모양 | 다크 모드, 모바일 레이아웃 |
| JavaScript | 동작 | 글 불러오기, 변환, 화면 전환 |

## 배운 점

> 세 기술은 서로의 일을 침범하지 않을 때 가장 깔끔하다.

- 구조는 HTML에, 모양은 CSS에, 동작은 JavaScript에 두면 고칠 곳이 분명해집니다.
- 글에서 나온 텍스트를 화면에 넣을 때는 반드시 이스케이프해야 안전합니다.
- 프레임워크 없이도 작은 블로그는 충분히 만들 수 있습니다.
